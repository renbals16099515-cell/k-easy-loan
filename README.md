# K-easy Loan

A new loan-management project, independent from the previous Secureloan project.

## Planned features
- Admin/Lender dashboard
- Borrower portal
- Secure authentication
- Automatic Loan ID generation
- New-loan and renewal requests
- Approval/rejection workflow
- Configurable interest rate (default 5% monthly)
- Daily, weekly, twice-monthly and monthly payment schedules
- Loan release date/time
- Payment and overdue tracking
- Lender management
- Reports and Excel-compatible export
- Responsive mobile-first interface
- Supabase database/authentication
- Vercel deployment

## Current status
Initial frontend only. Database and authentication will be added next.
